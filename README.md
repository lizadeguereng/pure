# Pure: An app purley for podcasts

Pure is a mobile podcast app built with Figma, React Native, Expo Go, and Firebase. This app revolutionizes the way we listen to podcasts by offering a sleek, focused, and intuitive user experience. Whether you're an avid listener or new to podcasts, Pure is designed to provide a distraction-free space — just podcasts, no noise.

# Objective
The main objective of this project was to extend the UI/UX development workflow into a complete Software Development Life Cycle (SDLC). This included:
- User Personas
- Journey Mapping
- Wireframing
- Project Planning
- Implementation & Testing

# Tech Stack & Tools

## Tool / Tech	Purpose
React Native v18.2.0	Ensures a clean, native mobile experience similar to Instagram or Pinterest
Expo Go v51	Allowed iOS development from a Windows machine using live device previews
Firebase v13.24.2	Real-time cloud database for seamless backend integration
Figma	Created all UI wireframes and design prototypes
Adobe Illustrator & Photoshop	Custom logo and branding design
# Key Features
## Account Management
- Account Enrollment: Sign up with name, email, username, and password
- Login: Sign in securely using your username and password
### Listening Experience
- Podcast Streaming: Basic listening functions including play/pause/seek
- Podcast Discovery: Search and explore podcasts and podcasters

Detailed Insights: View key information about podcasts and podcaster profiles

# UX/UI Design Strategy
## User Persona
Developed a fictional user profile to tailor functionality and design for the target audience.

 ## 10 Heuristic Evaluations
Assessed the interface using UX laws such as:
- Match Between System & Real World
- User Control and Freedom
- Consistency & Standards

## Cohesive Design
Maintained a consistent design theme throughout all screens.

## Visual & Branding Choices
- Black & White Color Scheme: Matches the app's name Pure, offering simplicity and elegance
- Custom Logos: Created three unique logos using Adobe Illustrator and Photoshop
- Stylized Fonts: Used varying fonts to give the app its distinct personality
= Expo Components: Stayed within the Expo ecosystem for full compatibility

## Wireframes
Created using Figma, covering all essential user journeys:

- Home
- Login
- Register
- Podcast Player
- Podcaster Profile
- Podcast Profile
- Account
- Search

Each frame was crafted to ensure accessibility, responsiveness, and visual flow.

# Why Pure?
Popular platforms like Spotify and YouTube cater to broad media needs. But this blend often overwhelms users looking solely for podcasts. Pure solves this by creating a dedicated podcast platform — clean, minimal, and user-focused.
No videos. No music. Just podcasts and you.
